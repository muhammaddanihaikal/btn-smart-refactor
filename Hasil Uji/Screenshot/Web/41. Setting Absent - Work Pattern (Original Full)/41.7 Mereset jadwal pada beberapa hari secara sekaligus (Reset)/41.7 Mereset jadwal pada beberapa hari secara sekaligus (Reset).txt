TEST CASE: 41.7 Mereset jadwal pada beberapa hari secara sekaligus (Reset)
Modul: Setting Absent - Work Pattern
Tipe: Positive Case (Normal)

LANGKAH PENGUJIAN:
1. Klik button Add Work Pattern.
2. Centang beberapa checkbox hari pada Set Working Schedule.
3. Klik button Reset.

HASIL YANG DIHARAPKAN:
1. Berhasil menampilkan form Add New Work Pattern.
2. Berhasil memilih beberapa hari.
3. Berhasil mengosongkan kembali (reset) jadwal pada seluruh hari yang dicentang secara bersamaan.
